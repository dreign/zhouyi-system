## 1. 项目概述

### 1.1 项目背景

周易作为中国传统文化的瑰宝，被誉为"群经之首，大道之源"。随着现代技术的发展，将传统周易术数与人工智能技术结合，能够为用户提供更加智能化、个性化的占卜与命理服务。

本项目整合了三个成熟的开源项目：
- **Fate** (Go语言)：专业起名工具，集成六大派综合算法
- **OpenDestiny** (Flutter)：紫微斗数+八字排盘，跨平台支持
- **Godwill** (Python)：周易64卦占卜，传统大衍筮法

### 1.2 产品定位

周易占卜系统是一个基于传统周易术数算法和人工智能技术的现代化占卜与命理服务平台。

**核心定位**：
- 技术定位：传统术数算法 + AI大模型 + 现代Web技术
- 市场定位：面向全球华人及对东方文化感兴趣的用户
- 服务定位：智能化、个性化、易理解的占卜与命理服务
- 文化定位：传承传统文化，用现代科技让周易智慧触手可及

### 1.3 目标用户

1. **传统文化爱好者** (30-50岁)
   - 对周易、命理、风水等传统文化感兴趣
   - 愿意深入了解，但缺乏专业指导
2. **年轻探索者** (18-35岁)
   - 对传统文化好奇，但觉得门槛太高
   - 偏好现代化、科技感的产品体验
3. **寻求人生指导者** (25-45岁)
   - 在人生重要节点需要决策参考
   - 希望获得客观、理性的分析
4. **起名需求者** (20-40岁)
   - 新生儿起名、公司起名、品牌起名
   - 需要结合命理和现代审美的名字
5. **海外华人及文化研究者** (全球分布)
   - 对中华文化感兴趣的外国用户
   - 需要中英文双语支持

### 1.4 核心价值

**对用户的价值**：
1. **便捷性**：无需专业术数知识，通过对话即可获得专业解读
2. **准确性**：整合三大开源项目的成熟算法，确保计算准确性
3. **个性化**：AI根据用户具体情况提供定制化解读和建议
4. **易理解**：将复杂的术数术语转化为通俗易懂的现代语言
5. **全面性**：涵盖易经占卜、八字命理、紫微斗数、起名、测字等多个领域

**对传统文化的价值**：
1. **传承**：数字化保存传统术数知识体系
2. **普及**：降低学习门槛，让更多人了解周易文化
3. **创新**：用现代科技赋能传统文化，焕发新的生命力

## 2. 需求分析

### 2.1 功能需求

#### 2.1.1 易经占卜模块

**起卦方式**：
1. **金钱卦**（推荐）
   - 用户摇动或点击
   - 系统模拟三枚铜钱投掷
   - 根据组合确定阴阳爻和动爻
   - 输出：本卦、变卦、动爻位置

2. **数字卦**
   - 用户输入1-6个数字（或随机生成）
   - 算法：数字除以8取余得卦，除以6取余得动爻
   - 适用：梅花易数风格

3. **大衍筮法**（高级功能）
   - 用户按传统"四营十八变"流程操作
   - 系统引导分步操作
   - 仪式感强，适合深度用户

4. **时间卦**
   - 用户选择当前时间或特定时间
   - 算法：将年月日时转换为数字起卦
   - 适用：快速占卜

**解卦功能**：
1. **基础解读**
   - 显示卦象符号、卦名、卦辞
   - 显示爻辞（特别是动爻）
   - AI解读：用通俗语言解释卦义

2. **深度解读**（付费功能）
   - 纳甲筮法：装天干地支、六亲
   - 世应分析：世爻代表自己，应爻代表对方
   - 旺衰判断：根据月建、日辰判断爻的力量
   - 生克关系：五行生克分析

3. **场景化解读**
   - 事业占卜：关注官鬼、妻财爻
   - 爱情占卜：关注官鬼、子孙爻
   - 财运占卜：关注妻财、兄弟爻
   - 健康占卜：关注父母、子孙爻
   - 学业占卜：关注父母、官鬼爻

#### 2.1.2 八字命理模块

**信息输入**：
- 出生日期（公历/农历）
- 出生时间（精确到小时）
- 性别
- 出生地点（用于计算真太阳时）
- 姓名（用于姓名学分析，可选）

**排盘功能**：
1. **四柱排盘**
   - 年柱、月柱、日柱、时柱
   - 每柱的天干地支
   - 真太阳时校准

2. **五行分析**
   - 日主旺衰判断
   - 五行力量统计
   - 喜用神、忌神判定
   - 五行缺失分析

3. **十神分析**
   - 比肩、劫财、食神、伤官
   - 正财、偏财、正官、七杀
   - 正印、偏印
   - 各十神在命局中的位置和力量

4. **神煞分析**
   - 天乙贵人、太极贵人
   - 桃花、红艳煞
   - 华盖、文昌
   - 羊刃、亡神等

5. **大运流年**
   - 十年大运排布
   - 流年运势分析
   - 大运与流年相互作用

**命理解读**：
1. **整体格局**：命局类型（身旺/身弱/从格等）、格局特点、优势与挑战
2. **性格分析**：根据日主和十神分析性格特点、优势特质、需要注意的方面
3. **事业财运**：适合的职业方向、财运特点、事业发展建议
4. **感情婚姻**：感情运势、婚姻时机、配偶特征
5. **健康运势**：身体健康关注点、五行与脏腑对应、养生建议
6. **流年运势**：当前年份运势、未来3-5年运势趋势、关键年份提示

#### 2.1.3 智能起名模块

**起名类型**：
1. **新生儿起名**：输入出生日期时间、性别、姓氏
2. **成人改名**：输入原姓名、出生日期时间、改名目的
3. **公司起名**：输入公司行业、成立时间、创始人八字
4. **品牌起名**：输入品牌定位、目标人群、行业特点
5. **英文名起名**：输入中文名、出生信息、偏好风格

**起名算法**：
1. **八字命理法**：排出八字，定日主旺衰，找出喜用神、忌神，优先选择补益喜用神的字
2. **五格剖象法**：计算天格、人格、地格、外格、总格，依81数理判断吉凶，确保五格皆为吉数
3. **三才五格法**：天格、人格、地格的三才配置，五行相生为吉，相克为凶
4. **笔画派**：按康熙字典笔画计算，笔画数理吉凶判断
5. **卦象派**：姓名笔画组成卦象，取卦辞吉意
6. **生肖派**：根据生肖选择宜用字，避开生肖忌用字
7. **音韵派**：声调搭配，避免不良谐音

**起名流程**：
1. **信息收集**：基本信息输入、AI对话引导（了解偏好、忌讳、风格）
2. **算法计算**：运行多种起名算法、筛选符合条件的候选字、组合成名字列表
3. **综合评分**：每个名字按多个维度评分（命理匹配度、五格吉凶、音韵美感、字义寓意、文化内涵）、按综合得分排序
4. **AI解读**：对每个推荐名字进行详细解读（字义解释、命理分析、五格数理、文化典故、寓意祝福）
5. **用户选择**：用户浏览推荐名字、可收藏对比多个名字、最终选择心仪的名字

#### 2.1.4 测字术模块

**取字方式**：
1. **随机取字**：用户随机输入一个字，或系统随机生成一个字
2. **姓名测字**：输入姓名中的某个字，或输入全名
3. **外应取字**：用户描述当前环境，AI提取关键信息作为测字对象
4. **拈字**：从预设的字库中随机抽取

**测字方法**：
1. **离合法**：将字拆解为多个部分、重新组合解读
2. **增损法**：在字上添加或减去笔画、形成新字再解读
3. **象形法**：由字形联想到具体物象、根据物象寓意解读
4. **会意法**：根据字义联想、结合语境解读
5. **谐音法**：借用同音字转换含义、进行占断
6. **五行法**：将汉字部首归入五行、分析生克关系
7. **八卦法**：将字形对应八卦、结合卦象解读

#### 2.1.5 AI对话系统

**对话场景**：
1. **占卜前引导**：询问占卜目的、引导用户提供背景信息、帮助用户明确问题
2. **占卜后解读**：解读卦象/命盘、结合用户情况分析、提供具体建议
3. **深度对话**：解答用户疑问、深入探讨相关话题、提供文化背景知识
4. **命理咨询**：解答命理问题、解释专业术语、提供学习建议

**对话特性**：
1. **上下文理解**：记住用户的历史对话、理解用户的问题背景、提供连贯的对话体验
2. **个性化**：根据用户画像调整对话风格、记住用户的偏好、提供定制化建议
3. **多轮对话**：支持多轮交互、逐步深入探讨、灵活应对各种问题
4. **知识库集成**：整合周易术数知识库、准确引用经典文献、提供权威解读

## 4. 系统设计

### 4.1 核心算法设计

#### 4.1.1 易经占卜算法

**大衍筮法起卦**：

```typescript
// 大衍之数：49根蓍草
const YAN_NUM = 49;

// 三变取爻
function change(grass: number, seed?: number): number {
    // 第一变
    let sky = seed ? (seed % (grass - 1)) + 1 : Math.floor(Math.random() * (grass - 1)) + 1;
    let land = grass - sky - 1;
    let human = 1;

    // 去除余数
    sky = sky - (sky % 4 || 4);
    land = land - (land % 4 || 4);
    human = human - (human % 4 || 4);

    grass = sky + land + human;

    // 第二变
    sky = seed ? ((seed * 7) % (grass - 1)) + 1 : Math.floor(Math.random() * (grass - 1)) + 1;
    land = grass - sky - 1;
    human = 1;

    sky = sky - (sky % 4 || 4);
    land = land - (land % 4 || 4);
    human = human - (human % 4 || 4);

    grass = sky + land + human;

    // 第三变
    sky = seed ? ((seed * 13) % (grass - 1)) + 1 : Math.floor(Math.random() * (grass - 1)) + 1;
    land = grass - sky - 1;
    human = 1;

    sky = sky - (sky % 4 || 4);
    land = land - (land % 4 || 4);
    human = human - (human % 4 || 4);

    grass = sky + land + human;

    // 计算爻值：6(老阴)、7(少阳)、8(少阴)、9(老阳)
    return Math.floor(grass / 4);
}

// 起卦（6爻）
function generateGua(seeds?: number[]): string {
    let guaCode = '';
    for (let i = 0; i < 6; i++) {
        const yao = change(YAN_NUM, seeds?.[i]);
        // 阳爻(1)：7、9；阴爻(0)：6、8
        guaCode += (yao === 7 || yao === 9) ? '1' : '0';
    }
    return guaCode;
}
```

```typescript
interface BaziResult {
    year: string;          // 年柱
    month: string;         // 月柱
    day: string;           // 日柱
    hour: string;          // 时柱
    wuxing: string[];      // 五行
    rizhu: string;         // 日主
    xiyong: string;        // 喜用神
}

function parseBazi(date: Date, time: string): BaziResult {
    // 1. 转换为农历
    const lunar = convertToLunar(date);

    // 2. 获取年柱
    const yearGan = getYearGan(lunar.year);
    const yearZhi = getYearZhi(lunar.year);

    // 3. 获取月柱（按节气）
    const monthGan = getMonthGan(yearGan, lunar.month, lunar.day);
    const monthZhi = DIZHI[(lunar.month - 1 + 11) % 12];

    // 4. 获取日柱
    const dayGanZhi = getDayGanZhi(date);

    // 5. 获取时柱
    const hourGan = getHourGan(dayGanZhi[0], time);
    const hourZhi = getHourZhi(time);

    // 6. 计算五行
    const wuxing = calculateWuXing([yearGan, yearZhi, monthGan, monthZhi,
                                     dayGanZhi[0], dayGanZhi[1], hourGan, hourZhi]);

    // 7. 判定喜用神
    const rizhu = dayGanZhi[0];
    const xiyong = determineXiYong(wuxing, rizhu);

    return {
        year: yearGan + yearZhi,
        month: monthGan + monthZhi,
        day: dayGanZhi.join(''),
        hour: hourGan + hourZhi,
        wuxing,
        rizhu,
        xiyong
    };
}
```

**三才五格计算**：

```typescript
interface WuGeResult {
    tianGe: number;        // 天格
    renGe: number;         // 人格
    diGe: number;          // 地格
    waiGe: number;         // 外格
    zongGe: number;        // 总格
    sanCai: string;        // 三才配置
}

function calculateWuGe(lastName: string, firstName: string): WuGeResult {
    const lastStrokes = getStrokeCount(lastName);
    const firstStrokes = getStrokeCount(firstName);

    // 天格：复姓相加，单姓+1
    const tianGe = lastName.length > 1 ? lastStrokes : lastStrokes + 1;

    // 人格：姓最后一字 + 名第一字
    const renGe = getStrokeCount(lastName.slice(-1)) + getStrokeCount(firstName[0]);

    // 地格：名的笔画和（单名+1）
    const diGe = firstName.length > 1 ? firstStrokes : firstStrokes + 1;

    // 总格：姓名总笔画
    const zongGe = lastStrokes + firstStrokes;

    // 外格：总格 - 人格 + 1（单姓单名固定为2）
    const waiGe = lastName.length === 1 && firstName.length === 1 ? 2 : zongGe - renGe + 1;

    // 三才配置
    const sanCai = getSanCai(tianGe, renGe, diGe);

    return { tianGe, renGe, diGe, waiGe, zongGe, sanCai };
}

// 81数理吉凶判断
function getLuckyScore(num: number): string {
    const remainder = num % 81 || 81;

}
```
