# 周易占卜系统 - 功能增补需求文档

## 1. 文档概述

### 1.1 文档目的

本文档详细描述了周易占卜系统新增功能的需求规格，旨在向用户/客户展示本次系统增强的全部功能特性。

### 1.2 文档范围

本需求文档涵盖以下两大模块的功能增强：
- 智能起名引擎
- 八字命理引擎

| :--- | :--- | :--- | :--- |

## 2. 需求背景

根据用户反馈和市场调研，现有系统需要增强以下功能领域：

1. **起名分析**：用户希望获得更全面的姓名分析，包括属相匹配、星座分析、音律和谐度等多维度评估
2. **八字命理**：用户需要更深入的命理分析，包括命宫胎元、神煞分析、大运流年等专业功能

本次功能增补旨在提升用户体验，提供更丰富、更专业的命理服务。

## 4. 功能需求

### 4.1 智能起名引擎增强

#### 3.1.1 属相分析

| 需求编号 | FR-NAME-001 |
| :--- | :--- |
| **功能名称** | 属相分析 |
| **需求描述** | 根据用户输入的出生年份，分析姓名与属相的匹配度 |
| **功能说明** | - 支持12生肖属相分析<br>- 判断姓名五行与属相的相生相克关系<br>- 提供匹配度评分和详细解释 |
| **输入** | 姓名、出生年份 |
| **输出** | 属相信息、匹配度、详细解释 |

#### 3.1.2 星座分析

| 需求编号 | FR-NAME-002 |
| :--- | :--- |
| **功能名称** | 星座分析 |
| **需求描述** | 根据用户输入的出生月份，分析姓名与星座性格的匹配度 |
| **功能说明** | - 支持12星座分析<br>- 分析星座性格特征与姓名寓意的契合度<br>- 提供性格特征标签 |
| **输入** | 姓名、出生月份 |
| **输出** | 星座信息、性格特征列表 |

#### 3.1.3 三才五格计算

| 需求编号 | FR-NAME-003 |
| :--- | :--- |
| **功能名称** | 三才五格计算 |
| **需求描述** | 计算姓名的天格、人格、地格、外格、总格 |
| **功能说明** | - 天格：姓氏数理+1<br>- 人格：姓氏与名字第一字数理相加<br>- 地格：名字数理相加+1<br>- 外格：总格+1-人格<br>- 总格：姓名总笔画数<br>- 提供五格数理吉凶判断 |
| **输入** | 姓名 |
| **输出** | 五格数理、吉凶判断、三才配置 |

#### 3.1.4 音律分析

| 需求编号 | FR-NAME-004 |
| :--- | :--- |
| **功能名称** | 音律分析 |
| **需求描述** | 分析姓名的发音、声调及和谐度 |
| **功能说明** | - 标注每个字的拼音和声调<br>- 判断平仄搭配是否和谐<br>- 提供音律和谐度评分 |
| **输入** | 姓名 |
| **输出** | 拼音标注、声调信息、和谐度评分 |

#### 3.1.5 字形分析

| 需求编号 | FR-NAME-005 |
| :--- | :--- |
| **功能名称** | 字形分析 |
| **需求描述** | 分析姓名中每个字的结构和笔画平衡 |
| **功能说明** | - 判断汉字结构类型（左右、上下、独体等）<br>- 分析笔画数是否协调<br>- 评估整体视觉平衡 |
| **输入** | 姓名 |
| **输出** | 结构类型、笔画数、平衡评估 |

#### 3.1.6 谐音分析

| 需求编号 | FR-NAME-006 |
| :--- | :--- |
| **功能名称** | 谐音分析 |
| **需求描述** | 检测姓名是否存在不良谐音组合 |
| **功能说明** | - 扫描常见不良谐音词汇<br>- 提供谐音风险提示<br>- 给出修改建议 |
| **输入** | 姓名 |
| **输出** | 不良谐音列表、风险等级、修改建议 |

#### 3.1.7 流行度分析

| 需求编号 | FR-NAME-007 |
| :--- | :--- |
| **功能名称** | 流行度分析 |
| **需求描述** | 分析姓名的使用频率和流行程度 |
| **功能说明** | - 提供姓名排名数据<br>- 判断名字的独特性<br>- 给出命名建议 |
| **输入** | 姓名 |
| **输出** | 流行等级、排名、建议 |

#### 3.1.8 阴阳平衡分析

| 需求编号 | FR-NAME-008 |
| :--- | :--- |
| **功能名称** | 阴阳平衡分析 |
| **需求描述** | 分析姓名中阴阳字的平衡情况 |
| **功能说明** | - 判断每个字的阴阳属性<br>- 统计阴阳字比例<br>- 评估平衡状态 |
| **输入** | 姓名 |
| **输出** | 阴阳分布、平衡状态、建议 |

#### 3.1.9 禁忌部首检查

| 需求编号 | FR-NAME-009 |
| :--- | :--- |
| **功能名称** | 禁忌部首检查 |
| **需求描述** | 根据性别检查姓名中是否包含不适合的部首 |
| **功能说明** | - 检查男性名字是否包含女性化部首<br>- 检查女性名字是否包含男性化部首<br>- 提供修改建议 |
| **输入** | 姓名、性别 |
| **输出** | 禁忌部首列表、修改建议 |

### 3.2 八字命理引擎增强

#### 3.2.1 命宫计算

| 需求编号 | FR-BAZI-001 |
| :--- | :--- |
| **功能名称** | 命宫计算 |
| **需求描述** | 根据出生月份和时辰计算命宫 |
| **功能说明** | - 命宫 = (月支 + 时支 + 1) % 12<br>- 命宫为人生归宿，影响性格与命运走向 |
| **输入** | 出生月份、时辰 |
| **输出** | 命宫地支、解释 |

#### 3.2.2 胎元计算

| 需求编号 | FR-BAZI-002 |
| :--- | :--- |
| **功能名称** | 胎元计算 |
| **需求描述** | 根据出生月份计算胎元 |
| **功能说明** | - 胎元 = 月柱干支往前推3个月<br>- 胎元为受孕月份之气，影响先天禀赋 |
| **输入** | 出生月份 |
| **输出** | 胎元干支、解释 |

#### 3.2.3 神煞分析

| 需求编号 | FR-BAZI-003 |
| :--- | :--- |
| **功能名称** | 神煞分析 |
| **需求描述** | 分析八字中的神煞信息 |
| **功能说明** | - 天德贵人：吉祥之神<br>- 月德贵人：福寿康宁<br>- 天乙贵人：贵人相助<br>- 文昌：学业优异<br>- 华盖：艺术天赋、玄学有缘<br>- 驿马：变动、迁移<br>- 桃花：异性缘佳 |
| **输入** | 八字四柱 |
| **输出** | 神煞列表、含义、影响 |

#### 3.2.4 十神分析

| 需求编号 | FR-BAZI-004 |
| :--- | :--- |
| **功能名称** | 十神分析 |
| **需求描述** | 分析八字中十神的分布和状态 |
| **功能说明** | - 比肩、劫财：朋友、同辈、竞争<br>- 食神、伤官：智慧、才华、创造力<br>- 偏财、正财：财富、收入<br>- 七杀、正官：官职、约束、挑战<br>- 偏印、正印：学业、贵人、智慧 |
| **输入** | 八字四柱 |
| **输出** | 十神分布、数量、状态 |

#### 3.2.5 旺衰分析

| 需求编号 | FR-BAZI-005 |
| :--- | :--- |
| **功能名称** | 旺衰分析 |
| **需求描述** | 精确判断日主的强弱状态 |
| **功能说明** | - 极旺：气势强盛，需泄耗克制<br>- 偏旺：气势较强，需适度平衡<br>- 中和：五行平衡，最为理想<br>- 偏弱：气势不足，需生助<br>- 极弱：气势衰微，需强力生助 |
| **输入** | 八字四柱、五行得分 |
| **输出** | 旺衰等级、描述、建议 |

#### 3.2.6 大运分析

| 需求编号 | FR-BAZI-006 |
| :--- | :--- |
| **功能名称** | 大运分析 |
| **需求描述** | 计算并分析人生各阶段的大运 |
| **功能说明** | - 计算8步大运（每步10年）<br>- 分析每步大运的干支、十神、五行<br>- 判断吉凶走向 |
| **输入** | 八字四柱、出生年份 |

#### 3.2.7 流年分析

| 需求编号 | FR-BAZI-007 |
| :--- | :--- |
| **功能名称** | 流年分析 |
| **需求描述** | 分析未来年份的流年运势 |
| **功能说明** | - 计算未来10年的流年干支<br>- 分析流年十神和五行<br>- 判断每年吉凶 |
| **输入** | 八字四柱、起始年份 |
| **输出** | 流年列表、十神、五行、吉凶 |

#### 3.2.8 综合命理分析

| 需求编号 | FR-BAZI-008 |
| :--- | :--- |
| **功能名称** | 综合命理分析 |

| **输入** | 完整八字分析结果 |
| **输出** | 八维度综合分析报告 |
