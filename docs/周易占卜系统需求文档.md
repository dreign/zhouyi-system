## 1. 产品概述

### 1.1 项目背景

《周易》被誉为"群经之首，大道之源"，是中国古代哲学的基石，衍生了影响深远的术数文化。随着传统文化的复兴和人工智能技术的发展，将传统周易术数与现代科技结合，为用户提供智能化、个性化的占卜和命理服务，具有重要的文化价值和商业前景。

本项目整合三个成熟的开源项目：
- **Fate**（Go语言）：专业取名工具，六大派综合算法
- **OpenDestiny**（Flutter）：紫微斗数+八字排盘，跨平台支持
- **Godwill**（Python）：周易64卦占卜，传统大衍筮法

通过整合这些项目的核心算法，结合DeepSeek大模型API的对话能力，构建一个现代化的周易占卜综合平台，为用户提供从起名、算命到人生规划的一站式服务。

### 1.2 产品定位

**周易占卜综合系统**是一个基于传统周易术数算法和人工智能技术的现代化占卜与命理服务平台。

**产品定位**：
- **技术定位**：传统术数算法 + AI大模型 + 现代Web技术
- **市场定位**：面向全球华人及对东方文化感兴趣的用户
- **服务定位**：智能化、个性化、易理解的占卜与命理服务
- **文化定位**：传承传统文化，用现代科技让周易智慧触手可及

### 1.3 核心价值主张

**对用户的价值**：
1. **便捷性**：无需专业术数知识，通过对话即可获得专业解读
2. **准确性**：整合三大开源项目的成熟算法，确保计算准确性
3. **个性化**：AI根据用户具体情况提供定制化解读和建议
4. **易懂性**：将复杂的术数术语转化为通俗易懂的现代语言
5. **全面性**：涵盖易经占卜、八字命理、紫微斗数、起名、测字等多个领域

**对传统文化的价值**：
1. **传承**：数字化保存传统术数知识体系
2. **普及**：降低学习门槛，让更多人了解周易文化
3. **创新**：用现代科技赋能传统文化，焕发新的生命力

### 1.4 目标用户

**主要用户群体**：

1. **传统文化爱好者**（30-50岁）
   - 对周易、命理、风水等传统文化感兴趣
   - 愿意深入了解，但缺乏专业指导
   - 需求：专业、准确、有深度的解读

2. **年轻探索者**（18-35岁）
   - 对传统文化好奇，但觉得门槛太高
   - 偏好现代化、科技感的产品体验
   - 需求：简单、有趣、易懂的入门体验

3. **寻求人生指导者**（25-45岁）
   - 在人生重要节点（事业、婚姻、健康）需要决策参考
   - 希望获得客观、理性的分析
   - 需求：实用、可操作的建议

4. **起名需求者**（20-40岁）
   - 新生儿起名、公司起名、品牌起名
   - 需要结合命理和现代审美的名字
   - 需求：专业、美观、寓意好的名字

5. **海外华人及文化研究者**（全球分布）
   - 对中华文化感兴趣的外国用户
   - 需要中英文双语支持
   - 需求：准确的文化解释和翻译

### 2.2 易经占卜模块

#### 2.2.1 功能描述
基于Godwill项目的周易64卦占卜功能，支持多种起卦方式，通过AI解读卦象，提供通俗易懂的占卜结果。

#### 2.2.2 起卦方式

**1. 金钱卦（推荐）**
- 用户输入：摇动手机/点击按钮6次
- 系统自动：模拟三枚铜钱投掷，记录正反面
- 算法：根据组合确定阴阳爻和动爻
- 输出：本卦、变卦、动爻位置

**2. 数字卦**
- 用户输入：输入1-6个数字（或随机生成）
- 算法：数字除以8取余得卦，除以6取余得动爻
- 适用：梅花易数风格

**3. 蓍草法（高级功能）**
- 用户输入：按照传统"四营十八变"流程操作
- 系统引导：分步提示用户操作
- 特点：仪式感强，适合深度用户

**4. 时间卦**
- 用户输入：选择当前时间或特定时间
- 算法：将年月日时转换为数字起卦
- 适用：快速占卜

#### 2.2.3 解卦功能

**1. 基础解读**
- 显示卦象符号、卦名、卦辞
- 显示爻辞（特别是动爻）
- AI解读：用通俗语言解释卦义

**2. 深度解读（付费功能）**
- 纳甲筮法：装天干地支、六亲
- 世应分析：世爻代表自己，应爻代表对方
- 旺衰判断：根据月建、日辰判断爻的力量
- 生克关系：五行生克分析

**3. 场景化解读**
根据用户选择的占卜场景，提供针对性解读：
- **事业占卜**：关注官鬼、妻财爻
- **爱情占卜**：关注官鬼、子孙爻
- **财运占卜**：关注妻财、兄弟爻
- **健康占卜**：关注父母、子孙爻
- **学业占卜**：关注父母、官鬼爻

#### 2.2.4 AI对话引导

**信息收集流程**：
1. 用户选择占卜类型（事业/爱情/财运等）
2. AI通过对话引导用户补充信息：
   - "您具体想了解什么方面？"
   - "目前的情况是怎样的？"
   - "有什么特别担心或期待的？"
3. 起卦后，AI根据卦象和用户信息生成个性化解读

**解读报告结构**：
- **卦象概览**：本卦、变卦、动爻
- **核心寓意**：用现代语言解释卦义
- **现状分析**：结合用户情况分析
- **趋势预测**：未来发展可能
- **行动建议**：具体可行的建议
- **注意事项**：需要警惕的方面

### 2.3 八字命理模块

#### 2.3.1 功能描述
基于OpenDestiny项目的八字排盘功能，根据用户出生信息排出四柱八字，分析命理格局，提供人生运势解读。

#### 2.3.2 信息输入

**必需信息**：
- 出生日期（公历/农历）
- 出生时间（精确到小时）
- 性别
- 出生地点（用于计算真太阳时）

**可选信息**：
- 姓名（用于姓名学分析）
- 当前年龄
- 已知的大运信息

#### 2.3.3 排盘功能

**1. 四柱排盘**
- 年柱、月柱、日柱、时柱
- 每柱的天干地支
- 真太阳时校准

**2. 五行分析**
- 日主旺衰判断
- 五行力量统计
- 喜用神、忌神判定
- 五行缺失分析

**3. 十神分析**
- 比肩、劫财、食神、伤官
- 正财、偏财、正官、七杀
- 正印、偏印
- 各十神在命局中的位置和力量

**4. 神煞分析**
- 天乙贵人、太极贵人
- 桃花、红艳煞
- 华盖、文昌
- 羊刃、亡神等

**5. 大运流年**
- 十年大运排布
- 流年运势分析
- 大运与流年相互作用

#### 2.3.4 命理解读

**1. 整体格局**
- 命局类型（身旺/身弱/从格等）
- 格局特点
- 优势与挑战

**2. 性格分析**
- 根据日主和十神分析性格特点
- 优势特质
- 需要注意的方面

**3. 事业财运**
- 适合的职业方向
- 财运特点
- 事业发展建议

**4. 感情婚姻**
- 感情运势
- 婚姻时机
- 配偶特征

**5. 健康运势**
- 身体健康关注点
- 五行与脏腑对应
- 养生建议

**6. 流年运势**
- 当前年份运势
- 未来3-5年运势趋势
- 关键年份提示

#### 2.3.5 AI个性化解读

**对话引导**：
1. 用户输入出生信息后，AI询问：
   - "您最想了解哪方面的运势？"
   - "目前有什么困惑或想解决的问题？"
2. 根据用户关注点，重点分析相关方面
3. 提供具体、可操作的建议

**解读风格**：
- 避免宿命论，强调"命理是参考，命运在自己手中"
- 用现代语言解释传统术语
- 提供积极、建设性的建议
- 鼓励用户发挥主观能动性

### 2.4 紫微斗数模块

#### 2.4.1 功能描述
基于OpenDestiny项目的紫微斗数排盘功能，排出紫微斗数命盘，分析星曜布局，提供详细的命理解读。

#### 2.4.2 排盘功能

**1. 三方四正**
- 命宫、身宫
- 财帛宫、官禄宫、迁移宫
- 夫妻宫、子女宫、疾厄宫
- 兄弟宫、田宅宫、福德宫、父母宫

**2. 星曜排布**
- 十四主星（紫微、天机、太阳、武曲等）
- 辅星（左辅、右弼、天魁、天钺等）
- 杂耀（文昌、文曲、红鸾、天喜等）
- 六煞星（擎羊、陀罗、火星、铃星、地空、地劫）

**3. 四化分析**
- 化禄、化权、化科、化忌
- 四化对命局的影响

**4. 大限流年**
- 大限排盘（每10年一限）
- 流年排盘（每年一运）
- 流月排盘（每月一运）

#### 2.4.3 命理解读

**1. 命宫分析**
- 主星特性
- 命格特点
- 性格特质
- 人生方向

**2. 十二宫详解**
- 每个宫位的星曜组合
- 宫位之间的相互关系
- 各宫位的运势特点

**3. 综合运势**
- 事业运、财运、感情运
- 健康运、学业运
- 人际关系运

**4. 流年大限**
- 当前大限运势
- 流年运势分析
- 未来运势趋势

#### 2.4.4 AI解读

**解读重点**：
- 紫微斗数术语较多，AI需要用通俗语言解释
- 重点分析用户关心的宫位
- 结合星曜特性给出建议
- 强调"知命而不认命"的积极态度

### 2.5 智能起名模块

#### 2.5.1 功能描述
基于Fate项目的专业取名功能，结合八字命理、五格剖象、三才五格等多种算法，为用户提供智能起名服务。

#### 2.5.2 起名类型

**1. 新生儿起名**
- 输入：出生日期时间、性别、姓氏
- 输出：符合命理的好名字列表

**2. 成人改名**
- 输入：原姓名、出生日期时间、改名目的
- 输出：改善运势的新名字建议

**3. 公司起名**
- 输入：公司行业、成立时间、创始人八字
- 输出：利于发展的公司名称

**4. 品牌起名**
- 输入：品牌定位、目标人群、行业特点
- 输出：符合品牌调性的名称

**5. 英文名起名**
- 输入：中文名、出生信息、偏好风格
- 输出：与中文名谐音或寓意相符的英文名

#### 2.5.3 起名算法

**1. 八字命理法**
- 排出八字，定日主旺衰
- 找出喜用神、忌神
- 优先选择补益喜用神的字

**2. 五格剖象法**
- 计算天格、人格、地格、外格、总格
- 依81数理判断吉凶
- 确保五格皆为吉数

**3. 三才五格法**
- 天格、人格、地格的三才配置
- 五行相生为吉，相克为凶

**4. 笔划派**
- 按康熙字典笔画计算
- 笔画数理吉凶判断

**5. 卦象派**
- 姓名笔画组成卦象
- 取卦辞吉意

**6. 生肖派**
- 根据生肖选择宜用字
- 避开生肖忌用字

**7. 音韵派**
- 声调搭配
- 避免不良谐音

#### 2.5.4 起名流程

**1. 信息收集**
- 基本信息输入（出生日期、性别、姓氏等）
- AI对话引导：
  - "对名字有什么特别的要求吗？"
  - "偏好什么风格的字？"
  - "有没有忌讳的字或音？"

**2. 算法计算**
- 运行多种起名算法
- 筛选出符合条件的候选字
- 组合成名字列表

**3. 综合评分**
- 每个名字按多个维度评分：
  - 命理匹配度
  - 五格吉凶
  - 音韵美感
  - 字义寓意
  - 文化内涵
- 按综合得分排序

**4. AI解读**
- 对每个推荐名字进行详细解读：
  - 字义解释
  - 命理分析
  - 五格数理
  - 文化典故
  - 寓意祝福

**5. 用户选择**
- 用户浏览推荐名字
- 可收藏、对比多个名字
- 最终选择心仪的名字

#### 2.5.5 名字分析功能

**输入**：任意姓名
**输出**：
- 五格剖象分析
- 三才配置分析
- 八字匹配度
- 音韵分析
- 字义解读
- 综合评价

### 2.6 测字术模块

#### 2.6.1 功能描述
基于传统测字术，通过分析汉字结构、笔画、意象来占卜吉凶，结合AI解读，提供有趣的测字体验。

#### 2.6.2 取字方式

**1. 随机取字**
- 用户随机输入一个字
- 或系统随机生成一个字

**2. 姓名测字**
- 输入姓名中的某个字
- 或输入全名

**3. 外应取字**
- 用户描述当前环境
- AI提取关键信息作为测字对象

**4. 拈字**
- 从预设的字库中随机抽取

#### 2.6.3 测字方法

**1. 离合法**
- 将字拆解为多个部分
- 重新组合解读

**2. 增损法**
- 在字上添加或减去笔画
- 形成新字再解读

**3. 象形法**
- 由字形联想到具体物象
- 根据物象寓意解读

**4. 会意法**
- 根据字义联想
- 结合语境解读

**5. 谐音法**
- 借用同音字转换含义
- 进行占断

**6. 五行法**
- 将汉字部首归入五行
- 分析生克关系

**7. 八卦法**
- 将字形对应八卦
- 结合卦象解读

#### 2.6.4 AI解读

**解读流程**：
1. 分析汉字结构、笔画、部首
2. 应用多种测字方法
3. 结合用户提问的背景
4. 生成通俗易懂的解读

**解读内容**：
- 字形分析
- 字义解读
- 五行属性
- 文化典故
- 吉凶判断
- 建议启示

### 2.7 大模型对话系统

#### 2.7.1 功能描述
集成DeepSeek API，实现智能对话功能，引导用户完善信息，提供个性化解读，解答用户疑问。

#### 2.7.2 对话场景

**1. 占卜前引导**

from fastapi import FastAPI, HTTPException

from godwill.divination import divinate
from godwill.gua_data import get_gua

app = FastAPI(title="Godwill API")

class DivinationRequest(BaseModel):
    method: str
    input: dict

@app.post("/api/divinate")
async def divinate_api(req: DivinationRequest):
    try:
        result = divinate(req.method, req.input)
        return {"code": 200, "data": result}
    except Exception as e:
        raise HTTPException(status_code=400, detail=str(e))

@app.get("/api/gua/{gua_id}")
async def get_gua_api(gua_id: str):
    gua = get_gua(gua_id)
    if not gua:
        raise HTTPException(status_code=404, detail="Gua not found")
    return {"code": 200, "data": gua}

func authMiddleware(c *gin.Context) {
    token := c.GetHeader("Authorization")
    if token == "" {
        c.JSON(401, gin.H{"error": "未授权"})
        c.Abort()
        return
    }
    
    // 验证token
    claims, err := validateToken(token)

    }

}
