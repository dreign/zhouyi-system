很多人在刚开始的时候都会想到底选哪个门派比较好，很多人有这种疑问就是因为你不知道整个体系的架构是什么样的，那我们就来逐一拆解一下这三个元素到底应该怎么去理解。

首先是宫位，宫就是我们看到的这每一个格子，紫微斗数有十二个宫，一共十二个格子，宫位里面所有的信息都会随着出生时间不同而发生变化，只有一个东西是不变的，每个人的命盘上都是相同的，这就是地支。地支代表固定的方位，比如说子是正北方，午是正南方，卯是正东，酉是正西方。

有时候有人会问哪个方位对我比较有利？这是很多人常问的问题，方位就是用地支来定位，除了方位之外地支也可以用来定位时间。例如2025乙巳蛇年，我们所有人去年的命宫都在巳宫，如果是今年就是马年，马年所有人的命宫就一起转到午宫，这就是我们所说的流年，每一年都在流动，后面都是以此类推。

所以在紫微斗数里面选方位时间是最简单的，因为十二个格子你看哪一个比较好，哪一个比较强，那就选哪一个，基本上一眼就看出来了。

除了时间，方位地支本身也有一些合冲害的关系，我们平时说的哪些生肖比较合哪些生肖相冲，在紫微斗数里面一句话六个字我就教会你，横是合对是冲，竖是害。那什么意思？你看好横着的箭头指到的两个是相合的，外面对外面，里面对里面，这应该一秒钟就记住了。以后人家问你什么生肖跟什么生肖比较合，你能记住这个横着的都是合的就可以了。

然后是相害的，同样的外面和外面两两不合，里面和里面也是两两不合，只不过变成竖着的来对比。

还有一个相冲，这个更好理解，对角线就是相冲，相害是相互不待见、看不上，相冲就是有竞争有冲突，这个合冲害就是传说中的地支的六合六冲六害，这个完全不用记，看一眼就知道了。

还有一些其他的基础知识，这里就不展开讲了，这里只要知道地支在紫微斗数里面是永远固定的就可以了，无论其他的东西怎么变，地支的位置永远是这样固定不会变的。

有时候会说，比如紫微坐寅就是紫微星和天府星在寅宫，七杀坐申就是七杀在申宫，就是因为地支永远是不变的，所以才能作为一个标记点来用，申宫永远在右上角，寅宫永远在左下角，其他宫位都是一样永远在固定的位置。

知道了地支再来看天干，天干有十个甲、乙、丙、丁、戊、己、庚、辛、壬、癸，配合地支的十二个干支的组合，就是阳配阳，阴配阴，一共就组成了六十组，也就是六十甲子干支纪年法。

大家可能不知道的是天干有什么作用，例如去年是乙巳年代表蛇年，刚才讲了地支有什么作用，这个乙是干嘛用的？除了去年的乙巳年还有丁巳年、己巳年、辛巳年、癸巳年，这些天干有什么作用？这是第一个重点，天干是能量变化的具体规律，天干才是术数中最玄幻的部分。

这样做个对比，去年是乙巳，同时还有丁巳、己巳、辛巳、癸巳，这样看就很容易知道同样的蛇年前面的天干是不同的，其实就是发明天干地支的人告诉我们看似都是蛇年，其实是完全不同的状况。

具体有什么不同？就是用天干来控制这一年是好还是坏，可以把天干想象成老天爷的脾气或者上帝的脾气，或者打游戏的时候每个固定的时间段都会给你刷一个不同的状态。当遇到这些不同状态的时候，有的人很适应、很契合他的天赋，这就是运气好的表现。

同样有的人会很倒霉，这就是和当下的时空能量不契合，不仅好运没有增加，可能还会叠加坏的运气，只要理解了这个概念才会明白什么叫运气，后面才谈得上如何运用改变或者趋吉避凶。
