# 周易命理系统中英文切换功能实现计划

## 1. 项目现状分析

**当前项目情况：**
- Next.js 14 (App Router) 项目
- 暂未实现任何国际化功能
- 所有文本均为中文硬编码
- 包含5个主要页面：首页、易经占卜、八字命理、紫微斗数、姓名分析、周易全书

**参考项目 (opendestiny-flutter) 国际化方案：**
- 使用静态 Map 存储翻译文本
- 支持中文简体(zhCN)、中文繁体(zhTW)、英文(en)三种语言
- 使用扩展方法(extension)实现字符串翻译

## 2. 技术选型

**选择方案：next-intl**
- Next.js 官方推荐的国际化方案
- 支持 App Router、Server Components
- 支持语言检测、语言切换、翻译文件管理
- 与参考项目方案兼容（核心翻译逻辑类似）

## 3. 实现步骤

### 步骤 1：安装依赖
- 安装 `next-intl` 包
- 配置 `next.config.mjs`

### 步骤 2：创建国际化配置文件
- 创建 `messages/` 目录
- 创建 `zh.json` (简体中文翻译)
- 创建 `en.json` (英文翻译)
- 创建 `i18n.ts` (国际化配置)

### 步骤 3：创建语言切换组件
- 创建 `LanguageSwitcher` 组件
- 支持中英文切换
- 支持语言状态持久化

### 步骤 4：修改根布局文件
- 更新 `app/layout.tsx`
- 添加语言提供者
- 修改 HTML lang 属性

### 步骤 5：修改导航栏和页面
- 创建公共导航组件 `Navigation`
- 更新所有页面使用 `useTranslations` hook
- 翻译核心UI文本（导航、按钮、标签等）

### 步骤 6：测试和优化
- 测试语言切换功能
- 验证翻译完整性
- 优化用户体验

## 7. 注意事项

1. **部分内容保持中文**：传统文化相关术语（如卦名、干支）保留中文或使用拼音
2. **语言切换体验**：切换语言时应保持当前页面状态
3. **SEO考虑**：搜索引擎应能识别不同语言版本
4. **用户偏好存储**：记住用户语言选择
